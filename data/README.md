# Data

The original participant-level dataset used in the TFM is **not included in this public repository**.

The original file contained participant-level psychological and sociodemographic information, including responses from multiple mental-health and personality instruments. Because this is sensitive research data, public redistribution requires an appropriate privacy, consent and data-governance review.

For reproducible portfolio demonstrations, use a synthetic or fully de-identified/approved dataset with the same variable structure.

See the main README for the analysis workflow and limitations.
